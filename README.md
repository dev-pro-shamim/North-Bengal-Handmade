# North Bengal Handmade Products BD 🌿🧺
**Official B2B Export Platform & Commercial Dossier**

> *"Ethically Handmade | Naturally Beautiful | Certified for Global Standards"*

An enterprise-grade, modern web platform designed and built for **North Bengal Handmade Products BD**, a verified handicraft manufacturer and exporter based in Kaunia, Rangpur and Uttara, Dhaka, Bangladesh.

---

## 🚀 Key Features

* **Complete 52 Handcrafted Products Gallery:** Studio-grade high contrast photography, interactive category filtering (Storage Baskets, Planters, Hampers, Trays, Rugs), live search, and full-screen lightbox inspection.
* **Home Page Animated Sliding Showcase:** Smooth horizontal sliding showcase with pause-on-hover inspection.
* **B2B Custom Quote & RFQ Requisition:** Direct factory requisition workflow (no retail "Add to Cart"), allowing international buyers to request custom sizes, private labeling, and FOB Chittagong pricing.
* **Government Regulatory Verification:** Public statutory credentials section featuring verified documents:
  * **ERC (Export Registration Certificate):** `260326211291422`
  * **BIN / VAT (Mushak-2.3):** `004681231-0102`
  * **e-TIN:** `465746253246`
  * **Trade License:** `No. 147` (Kaunia, Rangpur)
  * **Bank Reference:** Agrani Bank Ltd., Gazipur Corporate Branch
* **Enterprise Detail Pages:** Dedicated pages for Company Story (`/about`), Sustainability & ESG (`/sustainability`), Export Logistics & CBM Estimator (`/export-guide`), Certifications (`/certifications`), Product Gallery (`/gallery`), and Printable Executive Dossier (`/company-profile`).
* **Design & Typography:** Built with Google Poppins typography, obsidian dark tones, warm golden jute accents, and custom SVG vector logos.

## 📦 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/dev-pro-shamim/North-Bengal-Handmade.git
cd North-Bengal-Handmade
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env.local`:
```bash
cp .env.example .env.local
```

### 3. Run Locally
```bash
npm run dev
# Server will start on http://localhost:3000
```

### 4. Build for Production
```bash
npm run build
npm run start
```

---

## 🌐 Deployment on Vercel

1. Import this repository in [Vercel](https://vercel.com/new).
2. Framework Preset will be automatically detected as **Next.js**.
3. Add the environment variables from `.env.example` into **Project Settings ➔ Environment Variables**.
4. Click **Deploy**.
